# Audits & Test Results

This folder collects internal security audits and automated test results for
ADA Messenger. These are produced by the project maintainers; the project has
**not** undergone a formal third-party security audit.

| Document | Description |
|----------|-------------|
| [TEST_RESULTS.md](TEST_RESULTS.md) | Latest `ada-core` automated test run (unit + integration). |
| [FORENSIC_AUDIT.md](FORENSIC_AUDIT.md) | Forensic-resistance review of the encrypted on-device storage (Russian). |
| [FULL_AUDIT_REPORT.md](FULL_AUDIT_REPORT.md) | Full internal security review of the core and apps (Russian). |
| [SECURITY_REVIEW_MAILBOX_MANIFEST.md](SECURITY_REVIEW_MAILBOX_MANIFEST.md) | Review of the bridge mailbox & signed manifest flow (Russian). |

To reproduce the test results, see [TEST_RESULTS.md](TEST_RESULTS.md#how-to-reproduce).

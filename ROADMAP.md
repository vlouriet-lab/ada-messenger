# Roadmap

This document outlines planned improvements. Items are roughly ordered by priority.

## Near-term (v0.4.x)

- [ ] Independent security audit by a third party
- [ ] EV code-signing for the Windows installer
- [ ] Google Play / F-Droid publishing pipeline
- [ ] Push notifications via FCM (background message delivery on Android)
- [ ] iOS client (Swift + ada-core via UniFFI)
- [ ] Improved onboarding: QR pairing flow UX polish

## Medium-term (v0.5)

- [ ] Multi-device support (link multiple phones/desktops to one account)
- [ ] Message search (full-text, local only)
- [ ] Disappearing messages UI controls exposed to end-users
- [ ] Voice messages (in-chat audio clips)
- [ ] Screen sharing in video calls
- [ ] macOS/Linux desktop builds (Compose Multiplatform already cross-platform)

## Long-term

- [ ] Federated bridge network (community-run bridge operators)
- [ ] Pluggable transports (obfs4, Snowflake) for deep packet inspection evasion
- [ ] Hardware security key support (FIDO2 / passkey for identity unlock)
- [ ] Formal threat-model document and reproducible builds

---

This roadmap reflects intentions, not commitments. Priorities can shift.
Contributions toward any of these items are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
